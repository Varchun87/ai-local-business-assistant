# Security Policy

## Supported Versions

Проект находится на стадии MVP. Исправления безопасности принимаются для текущей ветки `main`.

## Reporting a Vulnerability

Не публикуйте уязвимости в открытых issues, если они раскрывают токены, персональные данные, обходы авторизации или unsafe AI-поведение.

Создайте private security advisory в GitHub или свяжитесь с сопровождающим проекта.

## Safety Scope

В медицинских и тревожно-чувствительных сценариях ассистент должен:

- Работать как административный помощник, а не врач.
- Не ставить диагнозы и не назначать лечение.
- Передавать рискованные обращения человеку.
- Использовать только проверенную базу знаний организации.
- Логировать создание записей и handoff-события.

## Secrets

- Не храните `.env` в репозитории.
- Используйте secrets-хранилище хостинга.
- Ротируйте токены Telegram, WhatsApp, CRM и OpenAI при утечке.
