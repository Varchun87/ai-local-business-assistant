# Contributing

Спасибо за интерес к проекту.

## Приоритетные направления

- Безопасные сценарии для административных ассистентов.
- Интеграции Telegram, WhatsApp, календарей и CRM.
- Улучшение UX лендинга и панели администратора.
- Тесты, документация и security checks.

## Правила

- Не добавляйте код, который выдает медицинские диагнозы или заменяет консультацию специалиста.
- В сценариях здоровья используйте handoff к человеку при риске, неопределенности или жалобах на состояние.
- Не коммитьте токены, ключи API, персональные данные и реальные диалоги клиентов.
- Описывайте изменения в pull request коротко и проверяемо.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm audit --omit=dev
```
